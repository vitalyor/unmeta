# Тон Unmeta

Unmeta говорит как спокойный знающий друг: коротко, тепло, по делу. Человек не обязан знать, что такое EXIF, — он хочет отправить фото и не переживать.

## Пять правил

1. **Коротко.** Одна мысль — одна строка. Если строку можно сократить без потери смысла — сокращаем.
2. **Простыми словами.** Говорим «скрытые данные», «где снято», «на что снято». «Метаданные» и «EXIF» — только в подробном просмотре или с пояснением рядом.
3. **Спокойно, без страшилок.** Объясняем, чем данные могут навредить, одним фактом, а не угрозой. Никаких «ВНИМАНИЕ!», «опасно!», красных капслоков.
4. **Честно.** Не говорим «чисто», если не уверены. Если не получилось — так и пишем, и сразу говорим, что с оригиналом всё в порядке.
5. **Мы, а не система.** Продукт говорит «мы» («Нашли», «Удалим»), к человеку — на «вы» (с маленькой буквы). Без пассива и канцелярита.

## Так / не так

| Так | Не так |
|---|---|
| Есть точная геопозиция — будет удалена | Обнаружены GPS-координаты в EXIF (55.7558, 37.6173) |
| Модель телефона и её серийный номер — по нему ваши снимки можно связать между собой | Метаданные устройства (Make/Model/SerialNumber) представляют угрозу деанонимизации |
| Этот формат мы пока не умеем чистить. Файл мы не трогали. | Ошибка: неподдерживаемый MIME-тип |
| Устройству не хватило памяти. Закройте другие вкладки и попробуйте ещё раз. | Out of memory. WASM heap allocation failed |
| Файлы не покидают ваше устройство. | 100% БЕЗОПАСНО! Ваши данные под надёжной защитой! |
| Готово. Мы перечитали файл — лишнего не осталось. | Операция успешно завершена. |
| Большой файл — может не получиться. Попробовать? | Предупреждение: превышен рекомендуемый размер файла |

## Английский

Не перевод, а такой же живой текст: plain English, contractions (we’ll, can’t), sentence case в заголовках и кнопках («Download all», не «Download All»). Апостроф — типографский `’`, чтобы не ломать ICU.

| Do | Don’t |
|---|---|
| Exact location found — will be removed | GPS metadata detected |
| We can’t clean this kind of file yet. Your file is untouched. | Unsupported file format error |

## Мелочи

- Кавычки: в русском «ёлочки», в английском “curly”. Тире — длинное `—` с пробелами. Многоточие — `…` одним символом.
- Буква «ё» — всегда.
- Числа файлов — только через ICU plural (`{count, plural, one {…} few {…} many {…} other {…}}`), никогда «файл(ов)».
- Кнопки — глагол в инфинитиве: «Очистить», «Скачать», «Поделиться».
- **Эмодзи в интерфейсе не используем, иконки — забота разметки.** В строках только текст, и каждая строка понятна без иконки рядом.
